# Stacks and Queues: Array vs. Linked List

## Description
This project implements stacks and queues using arrays and linked lists. It includes a menu-driven program, error handling, a balanced-parentheses checker, and a print queue simulation.

## Files
- `array_stack.py` — Array-based stack.
- `linked_stack.py` — Linked-list-based stack.
- `array_queue.py` — Circular array queue.
- `linked_queue.py` — Linked-list-based queue.
- `main.py` — Main menu, test driver, and application exercises.
- `analysis.md` — Written answer to the analysis question.

## Requirements
- Python 3.x
- No additional packages required.

## How to Run
1. Save all Python files in the same folder.
2. Open a terminal in that folder.
3. Run:

   `python main.py`

4. Select an option from the menu.
5. Follow the instructions displayed on the screen.

## Features
- Stack operations: push, pop, peek, is_empty, and is_full.
- Queue operations: enqueue, dequeue, peek_front, is_empty, and is_full.
- Underflow and overflow error handling.
- Circular queue wrap-around.
- Balanced-parentheses checking.
- Print queue simulation using FIFO order.
